Labelling Field Recordings: A System That Keeps Your Archive Useful

Updated October 2026 · Field recording and nature sounds

Quick answer

A field recording archive is only useful if you can find what you need. Use a consistent naming pattern with the date, the place and the content, keep the metadata that matters, such as conditions and equipment, and store notes alongside the files. A simple system, applied every time, keeps an archive usable for years.

Field recording produces a lot of files, and they quickly become impossible to use if they are not labelled. A file called recording_0042 tells you nothing six months later. A good label tells you what the sound is, where it was recorded, when, and under what conditions. A consistent system turns a pile of recordings into a library that can be searched and reused, and it is one of the most valuable habits a recordist can build.

This post sets out a naming system, the metadata worth keeping, how to store notes and how to keep the archive usable over time.

Why labels matter

Labels make recordings findable. When you need a particular sound for a project, a good label lets you find it in seconds rather than hours. Labels also protect the value of the work: a recording whose origin is unknown is harder to trust and harder to use, while a well-labelled one carries its context with it.

A naming pattern

Use a consistent pattern for every file, such as date, place, content and take number. For example, 2026-10-25_harbour_gulls_take02. Put the date first, so files sort in order, and avoid spaces and symbols. Keep the same pattern across all recordings, so the archive looks and behaves consistently.

What metadata to keep

Beyond the name, keep the details that help you use the sound later: the exact place, the time, the weather, the equipment and the settings, the microphone position and the distance. Note any species, people or events in the recording, and any permission or licence. Store this information in a text file or in the file’s metadata fields, if your recorder or software supports them.

Keep notes beside the files

A simple notes file for each session is one of the most useful records. Write down the place, the conditions, what you heard and what you intended. The note is much easier to write on the day than to reconstruct later, so make it part of the routine at the end of each session.

Use folders carefully

Folders help, but they can become a maze. A simple structure, such as one folder per location and one subfolder per date, works well for most people. Avoid deep nesting, which makes files hard to find. Keep the folder names consistent with the file names, so both can be searched.

Keep the archive usable over time

Review the archive every few months. Check that the names are consistent, that the notes match the files and that the backups are working. Fix any file that has lost its label, and add the missing details while you still remember them. An archive that is maintained stays useful for years.

Common mistakes

  • Leaving the camera or recorder’s default file names in place.
  • Labelling only the date, so the place and content are lost.
  • Failing to write the notes at the end of each session.
  • Using inconsistent patterns, so searching becomes unreliable.
  • Letting the archive grow without review.

A simple routine

  1. Rename every file with the date, place, content and take number.
  2. Write a short session note with the conditions and the intent.
  3. Record permissions and licences in the note.
  4. Store the files and notes in a simple folder structure.
  5. Review the archive every few months, and fix any gaps.

Labels for the people who use the archive

An archive is often used by someone else, such as a collaborator, an editor or you, years later. Write labels a stranger could follow: the place, the date, the subject, the equipment and a short description of anything unusual. A label that only makes sense to you will not help once your memory of the trip has faded.

Check the labels at the end of each trip

Before you put the cards away, look through the files and confirm that each folder and each name matches your notes. Fix any gaps while you still remember the sounds. A ten-minute check after each trip prevents a much longer search later.

Recording a short voice note on site

Speak a short note into the recorder at the start of each file, saying the place, the date and the subject. The spoken note travels with the audio, and it survives when a written label is lost or a folder is renamed. Keep it short and speak clearly, since a mumbled note is hard to use later. Repeat the note when the scene changes.

Limits

A labelling system is only as good as its consistency. The best system is one you will actually use, so keep it simple enough to apply every time. Adjust the pattern if you find it awkward, but change it early, before the archive grows too large to rename.

Frequently asked questions

What should a file name include?

The date, the place, the content and the take number, in a consistent pattern.

Why keep notes if the file is labelled?

Notes hold the conditions, the intent and any permission, which a file name cannot.

How often should I review the archive?

Every few months, to fix gaps and check that the notes match the files.

Should I use folders or file names?

Both, with a simple folder structure and consistent names, so either can be searched.
